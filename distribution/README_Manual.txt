GalMaster 한국어 패치 v1.0.0 (수동)

1. 게임을 종료하고 ZIP을 전부 압축 해제합니다.
2. 기존 모드가 있다면 게임 폴더의 BepInEx, winhttp.dll, doorstop_config.ini, .doorstop_version을 별도 위치에 백업하세요.
3. '패치파일' 안의 모든 파일과 폴더를 GAL PRO MASTER.exe가 있는 폴더에 그대로 복사·병합·덮어씁니다.
   '패치파일' 폴더 자체를 게임 폴더 안에 넣으면 안 됩니다.
4. Steam에서 게임을 실행합니다. 게임 언어는 중국어 간체를 유지합니다.

복구: 게임 종료 후 이번에 복사한 파일을 제거하고, 기존 모드가 있었다면 설치 전 백업을 되돌리세요.
다른 모드가 없는 순정 게임에 설치했다면 BepInEx 폴더, winhttp.dll, doorstop_config.ini, .doorstop_version을 제거하면 됩니다.
다른 모드가 있는 경우 BepInEx 전체를 삭제하지 마세요. README의 변경 파일 목록을 기준으로 제거하세요.
수동판은 자동 백업을 만들지 않으므로 설치 전 백업을 보관해야 합니다.

지원: Steam 앱 4513880 / 빌드 24775635 / Windows x64 / 중국어 간체 설정
패치 버전: v1.0.0
게임 실행 파일: GAL PRO MASTER.exe

본편 대사·선택지, 메뉴·설정·저장/불러오기, 휴대전화 이미지, 엔딩·보너스 영상 한국어 자막을 포함합니다.
영상은 원본 그대로 재생하고 한국어 자막을 추가하므로 영상 속 중국어 문구는 남아 있습니다.
게임과 설치기를 동시에 실행하지 마세요. 기존 다른 모드 또는 이전 시험 패치가 있으면 먼저 백업·제거하세요.
게임 원본 파일과 세이브는 패치 대상에 포함되지 않습니다.
게임 업데이트, 다른 모드와의 병용, 다른 운영체제는 미검증입니다.
첫 실행은 초기화 때문에 시간이 걸릴 수 있습니다. 사용자 플레이 검수를 거쳤으나 모든 환경에서의 무결함을 보장하지 않습니다.
비공식 팬 패치입니다. 제3자_라이선스_고지.txt를 확인하세요.
오류 제보: https://github.com/etashi04/GalMaster/issues
장면·재현 순서·게임 빌드를 적어 주세요. 로그를 올릴 때 개인 경로를 지워 주세요.

검증 한계: 최종 설치기 화면·고배율 표시 및 최종 배포 ZIP의 전체 설치·복구 재검증은 미완료입니다.
